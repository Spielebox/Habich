Zettel drucken

Komplett schwarz-weiß, ohne Flächen – spart Tinte. Ein Zettel gilt für eine Runde, für ein ganzes Spiel braucht jede Person also 3 Zettel.

3 Zettel pro Seite, einfach an den Schnittlinien durchschneiden.

Digitaler Zettel

Schreiben: Feld antippen, mit dem Finger schreiben, „Fertig“. Vergleichen: Begriff antippen = umkreist, nochmal = durchgestrichen, nochmal = wieder frei. Stern antippen = ausmalen (nur bei umkreisten Begriffen). Zum Schluss „Auswerten“.

Tipp: Für mehr Platz zum Schreiben das Handy quer halten.

Spielregeln

Schreibt 3 Begriffe auf
Kurzregeln
  1. Frage vorlesen, alle schreiben heimlich 3 Begriffe in freie Felder. Kein Begriff doppelt. Das macht ihr für 3 Fragen.
  2. Dann liest reihum jemand einen Begriff vor. Alle anderen sagen nur „habe ich“ oder „nicht“.
  3. Treffer: umkreisen = 1 Punkt. Niemand: durchstreichen. Genau ein anderer: Stern ausmalen = +2.
  4. Reihen (von oben) 1 / 2 / 3 Punkte, Spalten (von links) 1 / 2 / 3 Punkte, wenn alle drei umkreist sind.
  5. Die Runde endet, sobald jemand keinen Begriff mehr vorlesen kann. 3 Runden sind ein Spiel.
